# Temporary Vercel Sandbox demo backend
Uses exact reviewed research implementation 3d1a8af42cfda4e0310d08fd2cde4130b88c3e71. No downgraded model. Free Hobby limits: max 45-minute session including initialization; 4 vCPUs / 8 GB memory subject to quota. Configure HF_TOKEN and DEMO_ADMIN_KEY (minimum 24 random characters) as sensitive production environment variables directly in the Vercel dashboard, then redeploy. Never commit credentials. Start via admin page, check /health on returned temporary URL, stop when done. The launcher uses Vercel OIDC, does not accept arbitrary commands, does not auto-create sessions for public requests and stops on launch failure. The pinned backend runs its raw-image smoke test before serving. Accuracy is a historical held-out experimental result, not a clinical guarantee. No Netlify production changes.
