# DermaScreen AI Vercel inference API
Backend-only deployment. Existing trained EfficientNet-B0 TensorFlow.js weights from presentation-ready, commit 3d1a8af42cfda4e0310d08fd2cde4130b88c3e71. CPU inference, no Hugging Face token. POST /predict accepts consent:true and base64 of exactly 224x224x3 RGB bytes, browser-side quality check and resize before sending. Netlify origins only (CORS is not authentication). Educational, non-identifiable authorized demonstration photos only. No intentional photo storage. 32.96% historical overall test accuracy; 55.95% belongs to separate Derm Foundation experimental classifier, NOT this model. GET /predict?smoke=1 computes a synthetic input. No claim of clinical validation.
