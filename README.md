# DermaScreen direct Vercel backend
Uses the existing seven-class Derm Foundation head with the validation-selected training pipeline. Historical experimental test accuracy 55.95%; not clinically validated. Set HF_TOKEN in Vercel production as a sensitive variable, redeploy. Build downloads authorized model privately into the function bundle; no weights or credentials in public source or static assets. Vercel 2 GB runtime memory and 4.5 MB payload limits apply. /health must return ready:true and /predict must pass raw-image test before integration. Use only authorized non-identifiable demo images.
